# Deepanwitha — Personal Portfolio Website

A responsive, full-stack personal portfolio showcasing creative technology, UI/UX design, and AI projects.

## Live Demo
- **Portfolio Website:** https://vercel.app

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (custom animations, accessible motion controls, responsive layout)
- **Backend:** Python (Flask, Flask-CORS)
- **Hosting:** Vercel

## Python Backend Features
- **`POST /api/contact`**: Validates and processes contact form submissions in Python, logs timestamps, and returns personalized JSON responses to the frontend.
- **`GET /api/health`**: Health-check endpoint reporting live Python Flask backend status.
